# 守望谷 v0.5.6A · 河里无树：真实河岸与开荒植被同源

> **已实现**。PR [#25](https://github.com/mastercook777/Little-Haven/pull/25) 合入 main，完成图形/模拟一致的河岸禁布及稳定植物锚点。下一阶段山居形制见 [v0.5.6B](V056B_COTTAGE_ARCHETYPES.md)，完整总规范见 [村居百态](V056_PIONEER_ARCHETYPES_ECOLOGY.md)。

## 本轮具体修正

- `src/simulation/creekCorridor.ts` 提供与 Three.js centripetal Catmull–Rom 曲线**实值一致**的采样、切线与最近距离，统一河面半宽 1.38、稳定河岸外缘 2.42；`riverArt.ts` 消费完全同源的曲线，不再让可见河道与寻路/布景各自解释不同折线。对高频路径/建房检查的近似坐标加了有上限的距离缓存；远离河道的地块快速跳过深入边线检测。
- `pioneerNaturalAnchors.ts` 把开荒松、竹、阔叶固定树抽成有 ID 的**模式专用自然锚点**。预先迁移三个有证据落水的旧坐标 `pine-3`、`pine-6`、`bamboo-5` 及其他不满足岸线/碰撞约束的坐标；原 v0.3 经典 `VALLEY_PINES`、`VALLEY_BAMBOO` 一字未动。
- 真实开荒同源树位用于实际保护 SAT 占用、A* 路网、固定松竹绘制、受保护阔叶树、季节叶片/花瓣/积雪、雨点落位。动态林木、采伐树桩和外圈灌木同时校验岛缘/河岸/道路/真实房屋/正在规划的工地和其它受保护自然物。
- 从 v4 旧存档恢复时，**保留**居民、住宅、工时、资源、路网以及所有原有建筑的地块，若新自然物与旧建筑/道路相交，仅在新开荒模式将该树向附近安全位置确定性迁移，结果一次性写进已有 v4 存档 JSON 的可选 `naturalAnchors` 字段；不能每次换季或读档重新骰树位。旧存档仍按原校验合法性导入。
- 未引入任何免费的木材/粮食/人口；不提前建造房屋；新档依旧 3 位创始居民和 0 永久建筑。
