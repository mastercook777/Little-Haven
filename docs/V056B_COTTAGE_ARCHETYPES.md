# v0.5.6B「家家有形」· 开荒住宅的四种真实轮廓

> 实施说明。以 [v0.5.6「村居百态」总规格](V056_PIONEER_ARCHETYPES_ECOLOGY.md) 为规则；此阶段只解决住宅 4 种形制和相应檐滴，不宣称全部生产建筑、选址/河岸生态升级完成。合并/CI 结果应在 PR 合入后更新。

全部使用原 `pioneerGrowth.ts` 住宅规划的合法 3.10×2.95 地块和现有 0.30 净空，真实建屋物资/工时/住房容量没有变化；不增加预制新屋、不在狭窄旧地块外面偷加附房。C3 的门、窗和真实正墙均同步退入前廊，不是仅把门装饰往后挪。

## 生成与旧档

- 以 `src/graphics/pioneerArchetypes.ts` 的 `PIONEER_COTTAGE_ARCHETYPES` 记录精确体型和曲面屋顶规格；从 `PioneerWorld.buildings` 不可变的建成时间与建筑 ID 排序推导同类住宅序号。第 1–4 家分别 C1–C4，第 5 家重新循环。房屋形制不依赖帧时钟、四季、材质随机数或未来人口。
- 不给存档添加第二套建筑注册表。旧 v4 存档的 `id`、`parcel`、`occupants`、`materialsSpent`、`workHours`、`loftAddedAt` 不变；重载后只要真实建屋历史相同，就得到相同形制。
- 新形制从施工开始使用同样的真实屋体比例，但只有确实到达落成阶段才有门窗、家具、附厢和木阁。木阁的竖向位置依每一种实瓦面曲线决定，不能继续固定在 2.17。
- v0.5.5 的 `pioneerRoofDrips` 依据相同屋型规格获取半檐尺寸和檐高；雨天的五条檐滴不再固定假设所有住宅高度一样。冬季雪仍由 v0.5.4 单一经典曲面瓦顶工厂生成。
- `pioneerVillage.ts.signatures()` 增加 `cottageArchetypes` 和 `uniqueCottageArchetypes`；Chromium 五年成熟村庄应在同屏至少有 3 类，且外轮廓不是只换材质。
