# v0.6.3 · 村落日常

守谷人能从村民走的路、经过的门和亮起的灯，看出他一天在做什么。观察一小段时间，可以看到有人留在田边，有人从上一处工地直接去取水，也有人先收工回家。村心仍有人做饭和交谈，住家、作业点和村心同时有人使用。

## 第一轮

- 保留现有工时、口粮和生产记账。村民从上一个可见地点出发，沿经过检查的线路抵达下一个任务。同一地点连续出工时持续干活。长短路程各需相应时间，同一整点的出发时间按人错开。
- 朝食多在家，午饭可以就地歇脚。公共灶台的少量席位轮换使用，傍晚闲谈限小组，并按天气和余粮决定是否聚集。
- 住户夜间通过自家门槛进屋。屋门随进出打开，屋内的人留在屋里，入住与入屋状态决定灯光。未分到住处的人仍留在营地。
- 验证成熟村庄同一连续时段的白天、饭点和入夜。对照旧版的往返次数、村心人数和屋外人数。旧开荒档存档继续加载，流年和逐段推进保持一致。

## 后续日常

第二轮把更多工作搬到真正的生活位置，例如进田收菜、在木作场卸货、在自家院里打扫。第三轮再让邻里互访、熟人串门和季节性聚会由关系、空闲与天气触发。
