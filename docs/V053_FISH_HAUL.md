# 守望谷 v0.5.3 · 一篓鱼，两段工

> 真实生计小闭环。承接 v0.5 渔棚和 v0.5.2 人物劳动守恒规则；只解决**渔获从河岸到村中**，不冒称完成全产业链物流。

## 实际体验
- 渔夫在可达河岸花一小时捕鱼：立刻扣有限鱼群库存，但**不增加全村口粮**。
- 渔棚暂存唯一一篓待运鱼；场景有可见暂存物。另一小时须由同一实际乡邻沿河岸到村心或已建粮仓的 A* 路线背运，呈现背鱼篓动作。送达才增加口粮和当日食物收入。
- 9:00、17:00 可安排返运；库满、路径不可达或无人时保留鱼篓，不再捕鱼、不凭空交付。返运与耕作、建筑和接客排他。
- 「渔篓归仓」里程碑，渔棚与粮仓检视显示累计捕获、实际运回、工时和积压；首次和每 24 次运鱼在日志记录具体人物。

## 存档与守恒
- v4 槽位不变；新增 `livelihood.fishTransport` 唯一待运批次、已送回总量、搬运工时与上次送达时间。
- 旧档历史渔获已经入粮，不在迁移时重新入账；缺运输台账才初始化为零。坏站点、幽灵搬运工、未来时间、超量篓鱼和伪造运量拒绝导入。
- 倍速、离线、流年都走每一小时的同一模拟路径。

## 验收边界
- `npm run test:sim`、`npm run check`、`npm run build:pages` 和桌面/390px Chromium 回归。
- 4 年自然成长，8 时捕鱼/9 时单独搬运，库满等待，旧档无伪历史，损坏档拒绝。
- 仍未实施：通用分品类库存、跨多小时真实步进、木材和田间搬运、鲜鱼腐坏或独立运输岗位。人物路线仍以现有小时内程序化移动绘制，不将其冒称连续实体物流。
