# 守望谷 · Sprint 7 · 从预制成长到有空间约束的自发生长

> 2026-11-03，依据用户秋雨场景的屋顶穿模反馈和 preview.6 试玩意见，先修规则，不在旧屋顶上继续加装饰。

## 1. 当前根因
- **旧系统 `villageCoreGrowth.ts`**：当劳动日达到 6/16/37/78 时，直接将原房屋整体替换成放大版，没有做邻居间的屋檐碰撞判定。即使建筑的墙面不相撞，屋顶、廊柱、台阶也可能互相穿插。
- **新系统 `villageEvolution.ts`**：商路、渡口、田园各有固定坐标的房屋和摊棚。这能表达三条路线，却不能回应真实新增人口、资源和土地余量，也不能保证生长多年后不互相撞。
- **地形与生活**：道路是画在地面的 ribbon，水道是独立的河床几何；目前模拟层没有可复用的“哪块地可以建、离谁多近”接口。只测河与固定商埠是不够的。

## 2. 目标
1. **先检查、后建造**：每次新增建筑和既有建筑扩建都要经过同一套二维 footprint/屋檐保护范围检查。
2. **路、水、山、桥为永久保护带**：不允许为了安置房屋挡住居民去工作、过桥，或把门开到悬崖。
3. **居住需求决定建设数量**：人口超过房屋容量才发起居住扩建；劳力和资源不足则停工，不因过了某一年强行换屋。
4. **种子决定不同村庄的地块选择**：同方向、同初始居民，只要不同种子/人口/资金演化就可能长到不同位置；相同条件快进与日步进得相同结果。
5. **不能建就不建**：搜索所有安全地块失败时留下“土地不足”的可追溯原因，而不是选一个和旧屋穿插的位置。

## 3. 地块规划合同

### 统一几何类型
- `WorldParcel`：`{id,kind,x,z,width,depth,rotation,clearance,accessX,accessZ,builtAt}`。
- 以实体**最大投影外轮廓**而不是墙体为 footprint。单体屋檐至少多预留 0.25–0.50 世界单位，侧廊和台阶实际占地也在尺寸里。
- 地块与建筑之间以**旋转矩形 SAT 碰撞检测**；山谷范围用几何角点与岛屿椭圆收口，禁止超边界。
- 道路用中心折线+通行净空的胶囊保护带，河道用同一曲线+岸坡净空，不允许建设在地形坡底。
- 现有酒馆、五个民居、练武坪、桥和发展分区均作为保留占地；新地块不能覆写这些布局。预制场所的细部装饰允许在同一建筑内部相邻，不能当成不同房子排斥。
- 建筑距离与可见工作点、道路接入距离联合评分；不是“随机找一个空格”就够。

### 分工
- `src/simulation/villagePlanning.ts`：纯数值、纯函数，不导入 Three，负责 OBB/SAT、道路/河岸/边界判定、候选地块搜索和稳定地块 ID。
- `src/simulation/villageGrowth.ts`：根据人口容量、资源与劳动日决定何时申请地块，将规划结果写入存档。
- `src/graphics/plannedSettlement.ts`：按已保存的地块位置与类型使用统一房屋工厂生成可见实体；不能自行另选地块。
- `src/graphics/villageCoreGrowth.ts`：旧酒馆/老居民屋扩建先测邻近整体模型包围盒，放不下时不强行升级外形，并保留后续竖向/异地扩建机会。

## 4. 可视成长节奏
- 新住户迁入 -> 现有住屋容量不足 -> 储蓄与材料满足 -> 选地 -> 打地基/施工 -> 落成 -> 继续正常生活。
- 不需要守谷人每天收集资源；守谷人的三条村庄方向只是发展偏好，不是每间房的固定位置。
- 短期验证 **同一发展方向不同种子** 生成至少 2 套无穿模地块布局，而不仅是三个不同路线预制图。
- 新建筑不允许一夜刷出来：有 `planned / building / completed` 状态，用世界时间而非帧时钟过渡。

## 5. 验收
- 单测：旋转矩形投影相交、仅边缘接触、河岸/道路净空、岛屿 4 角、地块两两不重叠、搜索失败返回 `null`、同 seed 再现、不同 seed 空间差异。
- 老村落：对五间旧民居和酒馆的每一成熟阶段计算实际渲染 Box3 并标记不合理邻接穿模；落成不能遮挡桥与河。
- 浏览器：相同镜头和季节，展示 1/2/4 年后新老建筑及 NPC，收集每个地块 ID、足印与被拒原因；动态生成的新屋能点击检查。
- 保持 `saveWorld`/import 兼容，不增加 server、云存档或付费模型依赖。
- 所有新建构件以 roof/eave 和 land-use 大体量为主，不额外制造更多零碎“装饰木块”。

## 6. 本轮范围边界
- 先交付 **稳定空间规划器 + 第一种可生长建筑** 的垂直切片，不宣称已经实现无限随机城市。
- 专业角色 GLB 骨骼与练剑动作资产另做美术生产管线，不与村庄碰撞热修一起混入。
- 若首次纯规则接入未通过真实浏览器河/屋/道路视觉审核，保持 Draft，不提前上线。
