# 守望谷 · v0.5.4「山居焕新」美术工程与验收标准

> 目标：将开荒版拉近已经打磨过的经典观察版的建模语言；不是复制经典版固定坐标村庄、不是重新规划建筑、也不是用素材皮肤替换仍有真实库存和工时的生长系统。主线方向始终是「江湖中的村庄」。

## 对比与确定的差距

| 表面 | v0.3 经典已具备 | 原 v0.5.3 开荒 | 本轮真实工作 |
| --- | --- | --- | --- |
| 房屋屋檐 | `villageBuildings.buildMountainRoof` 一体双曲面瓦片、起翘檐线与贴合雪面 | 平直屋板、几个重复檐口，部分粮仓叠箱 | 山居和粮仓直接复用经典同一几何工厂；每次**替换**旧屋顶，绝不叠加；从合法地块屋檐大小反推瓦面尺寸 |
| 立面与比例 | 雕木框、纸窗木格、双门、结构接榫 | 直方条、简易纸片 | 木门、砖阶、纸窗木格、檐下榫件、生活陶罐与吊灯；建筑 ID 决定小差异，不会重掷存档 |
| 人物 | `characterKit.dressCharacter` 弯曲布衣、帽子/披布、身份差异 | 头身腿为几何玩偶、附属工具 | **直接重用**经典 CharacterKit，装配到原乡邻上半身枢轴；保留所有脚下任务、工作动作、背篓、捕鱼杆和可点选人物 ID |
| 自然四季 | 丰富春夏秋冬树冠剪影与雪 | 主营地松竹常绿，季节主在草色和渲染上 | 少量受保护松位换季阔叶；春花、夏绿、秋黄、冬枝不产生幻影砍伐/地块冲突 |
| 渲染与性能 | 明亮略暖、薄雾与柔光 | 曝光偏淡，精修材质不足 | 向经典版材质与光照靠近；使用静态立面合批并增加可审计 visual signature |

## 不得回退的工程契约

1. 新档始终三人、一营火、零永久建筑。渔棚、茶棚、山居、粮仓仍取真实施工/库存/路径/需求状态。地基和梁架时不得显示成屋的瓦顶/贴窗。
2. 开荒山居屋顶宽深用**当前工厂的半檐尺寸**：classic geometry = `2*(halfWidth-.30)`、`2*(halfDepth-.32)`，因为经典工厂内部固定各扩 .30 / .32；这样得到与现有脚印一致的**真实曲屋檐**，而不是继承经典版 5+ 米房屋。
3. 不因美术模式修改 `PioneerWorld`、任何人物数字 ID、地块 registry、旧谷场景和 v4 存档槽；立面要在被保护的檐界内，山居和粮仓保持现有 entrance、door+Z、rotation。
4. 木阁改建沿同一建筑 ID/roof 继续可见，动态庄稼、渔篓、粮瓮、倒树、原有路网与建筑点选必须保留。冬雪按真实瓦面几何可见，不用漂浮大方块。
5. 共享盒子/材料不应被合批函数销毁，画面更新不得每帧重建大型建筑材质。传统开荒临时草棚、河岸渔棚、木匠露棚继续保持有区分度的草木材料，**不应全村统一刷蓝瓦**。

## 浏览器验收

- 纯三维单测：一体瓦顶只有一张 roof、Box3 屋檐在原保护范围内、立面可用静态合批、经典服装能装到创始居民、四季树冠不重复、原开局没有永久房。
- Chromium：现有 0/1/3/5 年、选地可点、鱼/茶/屋内生活动画、老 v0.3 入口及 390px 触控照常；新增断言成熟村山居与粮仓都有经典 roof，所有居民都有服装、保护树林按类型变化。
- **图像人工质量闸门**：固定镜头近景拍立面左右/后方各 1 张，春花夏荫秋叶冬雪各 1 张；检查阁楼与瓦面干涉、灯是否穿墙、屋檐是否遮道路/屋门、人物服饰肢体和森林/地块。技术 CI 不能自动证明审美合格。
- 性能：记录最新 Browser smoke 中 `getRendererInfo()` draw calls / triangles / geometries，和 v0.5.3 同镜头基线对照。仓库此前三年密集谷已约 1000+ draw calls，单次优化不应宣称低端 Android 性能已过。
