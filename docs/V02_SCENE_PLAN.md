# v0.2 山谷酒肆聚落 | 场景重构规范

## 视觉主题

**关键词**：山居 / 酒旗 / 竹影 / 小桥 / 瓦檐 / 火色灯笼 / 微缩模型。
保留 v0.1 清新简洁的岛屿轮廓、正交相机、低多边形体块、昼夜演出。不追求写实古建筑，不用外部纹理素材和付费 API；避免把中国风只做成菜单文案。

## 代表场景构图

从可见正面（+Z）看见主酒肆；左侧有农舍、药圃与矮墙；右侧河水、桥与从山外进入的小道；酒肆后方竹林影影绰绰，侧旁有练武坪和木人桩。

| 元素 | 造型与作用 | 系统关联 |
| --- | --- | --- |
| **无名酒肆（视觉核心）** | 两层木架灰瓦、翘檐、酒旗、红灯笼、酒坛与长凳 | 旅人到访和师徒相识地点 |
| **山间民居** | 白灰墙、木梁、深灰瓦、竹篱笆、柴堆 | 村民生活地点 |
| **练武坪** | 土地、木人桩、木剑架、石锁 | 阿青晨练，阶段性变化 |
| **竹林** | 节点分明的竹节、轻摇的叶片 | 识别山间武侠气质 |
| **石桥与山道** | 固定跨河通道、通往边缘的石板小路 | 沈问舟到访与阿青出谷 |
| **药圃/茶架** | 药草、晒架、土路 | 普通村民生活底色 |
| **结局建筑** | 竹隐剑庐 / 行脚茶亭 | 故事分支结果，须真实可见 |

## 3D 层级与预算

- Terrain / Water / Paths / Architecture / Props / Vegetation / Characters / StoryChanges。
- 建筑采用可复用构造函数，屋檐有起翘、瓦脊与木柱等最少可识别特征。
- 大量竹叶和小石块优先共享材质，不引入纹理网络请求。灯笼 emissive 随昼夜变化。
- 不添加重后处理，保持集显/移动浏览器可尝试运行的范围。
- 角色可辨认：村民衣襟、束发；阿青木剑；沈问舟斗笠/配剑。最少保留步行、待机、练武姿态差异。

## 体验脚本

- 开局：整体俯视，清晨酒肆亮着微光，村民向各自岗位走去，阿青在练武坪。
- 来客：江湖客沿东侧山道过桥前往酒馆，信箱更新为一次守谷机缘。
- 留客：师徒练剑；离村时阿青消失，风闻和时间显示他在外游历；归乡后剑庐出现。
- 放任：阿青受江湖客启发自学、随行商离村；归乡后茶亭出现。
