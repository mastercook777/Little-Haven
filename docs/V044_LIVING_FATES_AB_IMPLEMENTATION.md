# 守望谷 · v0.4.4-A/B 人物底座与真实羁绊（实施说明）

> 开发状态：PR #15，代码已进入审查／CI，**不是已发布的 v0.4.4 完整版**。
> 设计规范：[世界观圣经](WORLD_BIBLE_V1.md) · [众生命运系统](LIVING_FATES_SYSTEM_V1.md) · [ROADMAP](../ROADMAP.md)。

## 本次可验证的纵向体验

从新档「梁伯、陆娘、阿禾」出发：三人身份保持原样；村民逐时完成真实采集、修屋和同餐；在现有岗位、同一工作地点共同投入了足够小时的两人产生有来源的羁绊和可长期保存的人生片段；菜圃劳动经验可以在下一次真实田间采收中增加少量效率，但依然需要田地库存、到场劳动、仓储余量，不能凭空变出粮食。后来准备迁入的乡邻，先成为**持久候选人**，等待真实住房、粮水和农田条件满足后才成为常住人口。

这是 v0.4.4 的 A 与 B 底座，**尚未完成带命运分叉的 C**，绝不将共同吃饭写成“解锁隐藏身份”。

## 所有权与迁移

| 数据 | 唯一事实源 | 本次约束 |
|---|---|---|
| 常住人数、职业、姓名、住屋 | `PioneerWorld.founders` | 不建立第二份劳动人口；三位开荒者及六位老移民原名不变 |
| 人物背景与熟练度 | `livingFates.people[residentId]` | 由 `world.seed + residentId + generatorVersion` 稳定生成，只存一次，私密资料不进入普通 UI |
| 迁居候选 | `livingFates.pendingCandidate` | 有稳定 ID/来历/资料；未入住不消费粮水、不占住房、不计常住人口 |
| 羁绊 | `livingFates.relationships` | 有共劳或同席才建边；最多九名居民，关系不从画面距离虚构 |
| 永久人生记忆 | `livingFates.majorMemories` | 基于累计真实同工小时的事件，保留独立于 160 条滚动 journal |

`PioneerWorld.schemaVersion=4`、开荒双槽 KEY 和经典 v3 槽保持原样。无 `livingFates` 字段的合法旧 v4 JSON 仅补充**此刻已知的人物资料**，不生成过去四年的假事迹；老移民到谷日期未知时会在 UI 明示，不误写为“第 4 年才来到”。字段存在却伪造关系、技能等级、人物 ID 或未来时间的档案拒绝导入，不通过静默洗档解决。

原始 JSON 导出会包含真实的私有结构（任何持有者可以阅读源码／存档）；**游戏内人物卡**只读取 `publicFacts`、实际工作熟练度、已发生的合作记忆，绝不直接显示 `privateFacts` 或隐秘背景。

## 实际工时结算

- 逐时 `pioneerWorld.step` 已先选择一个互斥工作；随后 `settleLivingFatesHour` 按同一个 `world.minutes` 结算经历，无渲染帧推动。
- 田作成功时增加 `cultivation` 实践，林地采木／清林成功时增加 `wayfinding` 实践；每 24 小时达到一档熟练度，至多十档。
- 菜圃采收倍率至多 +12%，必须由该位居民实际承担 `farm`，且仍限于 `site.stock` 和仓库容量；没有田不会给粮。未经实际医疗／护路系统，不授予 `healing` 或 `protection` 虚构经验。
- 两人同一小时在**同一工作种类与工作目标**，才增加 `sharedWorkHours`；多人确实在公共地点用餐才增加 `sharedMeals`。普通交情取有限的慢速增长，至多 60，不直接触发身份揭秘。
- 共同承担 24 个有效工作小时的时刻，为二人写入固定 ID 的 `MajorMemory`，包含时间、参与人及工作地点线索；重复载入或更改流速不重发。这种记忆不是一次性增粮奖励。
- 关系和记忆只是在生活中生根；**方向 B 习武传承、江湖重背景、历史战乱压力均未在此切片触发**。

## 操作与验收

玩家可在右侧居民日常任务上点选名字，也可点击 3D 人物查看详情。手机用同一套人物按钮/触摸选择；只展示当前营生、是否拥有已知来谷时间、真实岗位练习、可追溯的邻里共事和重要人生片段。右侧资料并不指挥居民行动。

必须验证：

1. `npm run test:sim`：六类种子生成、原开荒三人、七日候选、旧 v4 迁移不改经济和历史、无工不涨、长年共劳与记忆、多个步进结果一致、篡改导入拒绝。
2. `npm run check` 和 `npm run build:pages`：Three.js 场景兼容、类型与静态部署。
3. `npm run test:browser`：桌面点人物查看公开手记不泄露私密字段，原有建筑、三年拓荒、手机触摸、旧谷无空白画面。
4. 四年、十年的长期审计和人工审美仍由后续审查完成，CI 通过不等于真实设备 FPS 或角色美术已达标。

## Skills 的实际使用

沿用仓库固定版本的 `threejs-game-director` 统筹范围，`threejs-gameplay-systems` 约束纯模拟工时与种子复现，`threejs-game-ui-designer` 的 UI/触摸交互规范收敛为轻量人物详情，`threejs-qa-release` 使用原有 Node + Playwright + Pages 闸门。没有新 3D 素材需求，因此不调用付费 3D / 图片 / 配音生成 Skill，也不引入在线 LLM。

## 下一切片边界

v0.4.4-B 尚缺真实救助／承诺、朋友间关系起伏、技能传授；v0.4.4-C 首选「留下的种子」：需要实际菜圃与两名长期共劳村民、牺牲短期收成、经历一季后在一块田上产生**有记录、可反驳、可永续使用**的产能差异；未达到条件就保持普通村庄自然发展。真实物流、完整命运多分叉和更广泛的世界压力留在 C/D，不能用文案或直接加库存冒充。
