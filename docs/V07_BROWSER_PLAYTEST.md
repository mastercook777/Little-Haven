## 这轮先看什么
1. 打开游戏，从新的存档前进两次「流年」，在「水脉与村路」机缘中选择**田园共居**、商路或渡口。没有回应也会由村民自行选田园。
2. 再前进约 7 个季节看原酒肆和民居如何尝试改建。**如果邻屋已经过近，扩建可能暂缓**，不再强制把新屋顶穿进隔壁。旧屋未变不一定是坏档，可能是安全约束生效。
3. 继续「流年」到约第 4–5 年，注意村中出现位置并非预设的**新民居**：地基 → 木构 → 完整房屋，居民资源和住房需求推动它自然发生。
4. 点击新屋，查看当前建设天数、坐标和选址原因。新屋必须避开主路、山桥、河岸、崖边、旧房屋和主要松竹。
5. 换另一个存档，选择同一路线再次观察。不同新档可能因创建时间种子不同在安全地块中找到**不同的新屋位置**；老档的已生成位置会被保存并在刷新后恢复。

## 重点验收问题
- **空间：** 屋顶、门廊、地基、树木是否还有穿插？是否有悬空屋、埋在山坡里的台阶、挡住桥的房子？
- **生活：** 建设是否在资源不足时暂停？民居是否随人口增长而增多？没有空间时是否保持原样而非强制建造？
- **历史：** 关闭网页再打开，建房位置、阶段和守望录是否一致？
- **相机：** 默认 3/4 视角、旋转视角与 390px 手机屏幕下是否均能观察新屋？
- **性能：** 如果出现卡顿，最好记录设备、年份、天气、已新增建筑数量。

## 已知边界
- 此次交付的是 **第一次能按需求自动选址的住屋生长**；原三条商路/渡口/田园地标仍为编排过的场景。
- 旧民居已有的穿模不会在本轮被强制挪屋消除。本轮机制阻止升级**新增或加重**穿模，部分升级会因此延后。
- 未建设可动态拓展的路网、迁入家庭的个体身份与完善的室内可达性；居民不会全自动形成无限规模的城市。
- 美术仍为低多边形程序化建模，并非已完成高品质 skinned GLB 人物；性能较高，低端安卓实机尚未验收。
