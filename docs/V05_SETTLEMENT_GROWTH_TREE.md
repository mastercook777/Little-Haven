# 守望谷 v0.5 · 村落成长树与里程碑系统设计草案 v1

> 状态：**讨论与预研规格，未实施，不代表 v0.5 已上线。**
> 前置：必须完成 [v0.4.x 打磨及可观察生活闭环](V04X_PIONEER_POLISH_PLAN.md) 中的 P0/P1 核心工作。
> **新增世界观基线**：[江湖中的村庄 / 世界观圣经 v1](WORLD_BIBLE_V1.md) 与 [众生命运系统 v1](LIVING_FATES_SYSTEM_V1.md)。迁入者的背景、职业技能、羁绊与长期命运是产业成长的重要驱动力；**方向 B 并非发展树的最终进阶**。
> 设计母题：**不是玩家点科技让村民变高级，而是村民经历生存、生产和交往，逐渐学会新的生活方式。** 守谷人只表达倾向；无操作仍可自治生长。

## 0. 成长树要解决什么，刻意不解决什么

### 三个主要矛盾

1. **四年后的目标断档**：有了几间屋子和九个居民之后，没有新的职业、设施和经济用途，放置失去下一个值得观察的变化。
2. **数量不等于生命力**：不能只把房屋扩到 30 间，而没有独立职业、外来往来、公共空间和新旧痕迹。
3. **单路径带来的程序感**：同一种子不同方针必须形成生产结构、人口结构和街区结构的分化，不能只是不同排列的既有四类设施。

### 整体成长循环

**需求 / 环境机会 → 学习与尝试 → 专业劳动 → 实际生产 → 村庄可见变化 → 声望 / 来访 / 新需求 → 下一次尝试。**

节点**没有消耗统一“科技点”**。材料与工时用于建造和试验，知识/工艺熟练度来自居民在真实工位劳动，人与人交换传入新的工艺。节点的解锁不是固定第 N 年，快进与 1× 计算必须一致。

## 1. 六条互有依赖的「生活方式」分支

| 主线 | 最初触发的真实问题 | 代表产出与岗位 | 新建筑与场景痕迹 | 关联分支 |
|---|---|---|---|---|
| **林业与木作** | 棚屋、修缮、扩大住户缺木/工具 | 木材、木构件、工具；樵夫/木匠 | 伐木林区、锯木台、木作棚升级、分层木料堆、可复苏森林 | 住房、矿业、商贸 |
| **农耕与民生** | 季节野食不足，人口上升 | 粮、种子、蔬菜、储粮；农人/厨娘 | 菜畦、田垄、粮仓、炊烟、公共灶、稻架 | 住房、商贸、文化 |
| **水岸与渔业** | 周围有可达水岸，村民有稳定食物或对水产需求 | 鲜鱼、干鱼、渔具；渔夫/制网人 | 小码头、鱼篓、渔棚、晒鱼架、捕鱼时令 | 农耕、商贸、交通 |
| **采石与冶铁** | 木工工具磨损，建筑需石基/金属器具 | 石料、矿石、锻具；采石工/矿工/铁匠 | 采石场、矿点、堆石、炉火、铁匠铺、锤音 | 林业、交通、商贸 |
| **道路与商贸** | 多余产品需要互换，外来行人需要可靠接待 | 交换物资、工具、贸易收入、商旅关系；商贩/驮夫 | 加宽土路、小集、桥头货摊、茶棚、客栈 | 各专业、名望、江湖 |
| **公共生活与文化** | 人口扩大后需要公共灶、议事与社交 | 归属感、工艺传承、村庄故事、地方名望；学徒/主持者 | 村心广场、集会屋、节庆装饰、学舍、故事墙 | 人口、商贸、江湖 |

**不做排他职业树。** 例如「河谷渔村」可有铁匠，「山林工坊」仍种菜。不同方向主要改变土地占用、劳动分工、建筑出现先后与街区构图，不会永久锁死另一个资源系统。

## 2. 成长节点由真实条件触发（示例数值尚待平衡）

每个节点必须定义：`id`、名称、需求原因、`requirements`、`evidence`、试验/建造成本、所得能力、世界中可见实体变化、可复原的因果事件、默认自治偏好，以及是否可以失去运营能力。

| 节点 | 建议门槛（非写死第几年） | 达成后真实改变什么 | 不满足时如何恢复 |
|---|---|---|---|
| **第一簇烟火** | 三人 + 可达临时营地 | 原始篝火、草席，三类基础采集 | 已有开局，无需重刷 |
| **避雨有屋** | 首次气候/居住需求 + 合法地块 + 木料/工时 | 真正棚屋入住，休息质量上升 | 采木/重新勘址 |
| **火塘成村心** | 首批居民安居 + 生活场所被使用 | 清退草席、石火塘、围坐与交谈 | 建议修火塘、修路 |
| **农田第一收** | 野食波动 + 适宜土地 + 耕作工时 | 稳定田畦、季节性收获/种植动作 | 休耕、扩田或去林地 |
| **家有新邻** | 空屋 + 足够口粮与饮水 + 可供的工作 | 迁入居民带姓名/职业/家居，任务调度增加 | 不迁入或迁出，不能凭空补人口 |
| **伐木成行当** | 采伐任务累积 + 木材需求 + 安全林区 | 工具/锯木台、职业差异、林地疏密变化 | 林地枯竭后转移伐木区 |
| **第一条成形乡路** | 足够多次真实路段通勤 | 更宽/更清晰路面、较可靠物流 | 地块受损需维护，不凭空通行 |
| **靠河吃饭** | 安全河岸 + 可用渔具/职业劳力 + 水产需求 | 渔获库存/渔棚/鱼篓和捕鱼动作 | 河禁渔季停工、转农作 |
| **石脉初开** | 发现近端矿点 + 可达路 + 工具/工作安全 | 石料/矿石，矿点视觉开采与堆料 | 矿脉枯竭或道路危险则停采 |
| **第一炉铁** | 矿石 + 燃料 + 会做基础锻具的居民 | 铁匠铺、修工具、铁制农具与下一类工坊 | 缺燃料/金属时关炉并示原因 |
| **山谷有集** | 可交换余粮/木料/鱼货 + 安全道路 + 来访客源 | 集市、交易/物流、外来居民的认识网络 | 供给不足时集市萧条不生产免费商品 |
| **名声传出去** | 旅人真实来访/交易/节庆或邻里故事连续发生 | 传闻、移民候选池、专业人才来访概率 | 名望会缓慢衰减，没钱不是立刻清零 |
| **烟火引江湖** | 可接待旅客的真实茶棚/酒肆 + 居民关系前提 | 旅人留宿与条件化武侠剧情，物理位置一致 | 无茶棚不能触发旧村固定酒肆剧情 |

**注：** v0.4.x 先做节点的记录和展示基础；真正渔业/采矿/铁匠/交易仅在 v0.5 实施。v0.5 的具体产出和劳动效率要按四年现有口粮审计结果调平，不在此草案硬锁产出数值。

## 3. 村庄的「名望」与「人口」不能只靠一次性数字跳变

### 3.1 人口分三类，不混在同一个数字里

- **常住乡邻**：有持久 `residentId`、真实住房与工作/生活目标，计入日常粮水消费；拥有来源、来时和关系事件。
- **临时商旅**：按真实交易线路与接待条件来访、停留和离去，不占常住住房，不应虚增总人口。
- **访学工匠／迁居候选人**：有传闻或工作邀请时短住，只有完成迁居和住房分配才转成常住居民。

### 3.2 迁入判断（构想的约束，而非现有公式）

候选人意愿取决于：
- **生计**：可达且实际空缺的岗位与未来劳动收益。
- **生活保障**：稳定的粮食/饮水、住宅容量、公共生活设施、健康与安全。
- **吸引力**：名望、贸易、师徒关系、亲友邀请、田园环境。
- **空间**：已经开垦的合法地块、道路和资源承载力。

建议使用**可解释评分 + 硬约束**：无空屋、无可达水源、没有长期粮食保障时，声望再高也不能让十个人瞬移入住。反之没有商业名望也能因亲友、环境和农业生计逐渐有人加入，避免强迫所有村庄发展成市场。

### 3.3 名望不是单一的金币换算

名望至少区分：
- **人情名声**：邻里互助、修缮、社会生活；吸引亲友/匠人。
- **手艺口碑**：林业/锻造/农品；吸引学徒与订单。
- **商路知名**：交通、集市、服务；吸引商旅。
- **山水声名**：文化、风景、节庆；吸引旅行/观光者。

这些不是四套沉重的货币，可以先做 1 个总量 + 4 个来源标签；关键是**每点名望必须能指向一次已发生的可见活动或设施**。

## 4. 玩家选择带来的三类截然不同的空间结果

| 发展偏好 | 早期实际策略 | 第 3–6 年预期实体外观 | 必须承担的代价 |
|---|---|---|---|
| **田园栖居** | 保住粮水，多开田/粮仓，慢迁入 | 林缘边的菜田与庭院、比较小的市集、社交村心 | 贸易速度慢，林木与粮地争土地 |
| **林间匠村** | 伐木、晒材、工具优先，升级木作 | 大片清出的工作空地、木棚和搬运道路，屋舍靠工区 | 森林再生压力、生产用地占据景观 |
| **河岸渔村** | 沿河寻找安全渔点，优先水产与鱼棚 | 明显的水岸活动、鱼篓/晒架/小码头、临河小路 | 季节禁渔、洪水/水岸净空 |
| **商道驿村** | 提升交通和交换，用余粮服务商旅 | 加宽路、茶棚/货摊/客舍，更多过客但未必更多常住居民 | 消耗运输工时、公共设施维护 |
| **山谷慢生活** | 降低扩张强度，优先修缮和环境 | 少数舒适长寿的住屋、乡邻交往、树林保存较多 | 专业职业解锁慢但不会被判输 |

**必须验证**：同种子换方针，至少出现不同的资源区布局、街道路线、岗位占比和主要公共设施。不能把上表理解为五套固定的预制地图，玩家中途应能改变发展方向。

## 4.5 人物驱动的成长节点（世界观补丁，设计基线）

原有的生产条件/资源节点仍成立，但需要增设**人是否真正具备能力、是否愿意留下、是否有人愿意学**等可验证前提：

| 节点 | 原本经济条件 | 人物与世界额外条件 | 可持续结果 |
|---|---|---|---|
| 林间木作进阶 | 林地、木材、木作棚、实际工时 | 有持续工作的木匠或由老匠人教出的学徒 | 更好工具/修缮，工艺传承可在人物离开后保留 |
| 山路成商道 | 已开垦合法地块、真实路网、往来需求 | 有懂路况的人提出、谷内有人愿投入修路；历史商路压力影响客流 | 更安全有效的路，旅人可能来，也可能破坏避世氛围 |
| 河岸渔业 | 安全河岸、季节性鱼类资源 | 有愿意学捕鱼或自带技艺的人；不能凭一个按钮让所有人同时变渔夫 | 真正的捕鱼工时、鱼获与可能出现的鱼棚 |
| 山谷有客 | 稳定口粮、客房/茶棚、路况 | 来客有真实来源、可能受战乱/商贸影响，不能直接算常住人口 | 旅人带来新的手艺、关系和江湖线索 |
| 武学传承（可选） | 合法场地、持续温饱与训练时间 | 长期住民愿意传授 + 学徒愿意学习 + 信任与必要事件 | 一处习武/互助之地，不使全村自动成为门派 |

人物是**约束与机会**，不是免费资源包；技能只能改变可执行工单/岗位的真实效率与候选方案。

## 5. 系统建议与代码边界

### 5.1 数据接口草案（非当前实现）

- `MilestoneDefinition`：前提列表（真实 world facts）、候选提案、默认自治、可见世界后果；数据静态。
- `MilestoneInstance`：`id,status=hidden|known|eligible|active|completed|blocked,createdAt,completedAt,causeEventIds`。
- `DevelopmentDirection`：多轴权重，时间变化有迁移成本；跟 v4 的 `policy` 兼容映射而非直接丢档。
- `IndustrySite`：聚合资源节点 `kind,stock,capacity,renewal,workers,access`，由 `ForestPatch/MineDeposit/FishingReach` 分别实现。视觉树/石/鱼由同一个 site 派生，绝不在渲染帧里偷偷加库存。
- `ResidentProfession` 和 `JobAssignment`：身份、熟练度、岗位需求与阶段目标；允许失业/转职，不能凭一个新增建筑把所有人物一键改职业。
- `VillageReputation`：有来源、有缓慢变化、可追溯的村庄吸引力。
- `VisitorOrMigrant`：真实来访流程、停留时间、是否有工作与住宿、是否成功入户。

### 5.2 一次节点完成的事务

1. 居民状态/资源/旅客行为让前提成立；提交具有稳定 ID 的候选节点。
2. 居民自主或守谷人低频建议确定优先方向；只改变调度权重。
3. 若需要建筑：勘地 → 净空与河岸/路径校验 → 人员备料 → 真实施工 → 完成。
4. 若需要工艺：有人在真实工位学习/练习/完成可审核工作量。
5. 消耗与输出只结算一次；节点触发不自动凭空给材料/人。
6. 更新既有世界状态与渲染实体，守望录写下谁为什么做成这件事。
7. 读档/切槽/季节快进重复计算不会二次完成同一节点。

### 5.3 地图和性能约束

更大的地图不是更多完整实体同时更新。资源库存和远端就业可按小时/天抽象结算，近镜头使用少量有意义的动作和 instancing；伐木和采矿动画由持久任务事件驱动，而非对每棵树都做经济模拟。

v4 的河流/terrain、路径/建筑净空、资源坐标必须完成统一后，v0.5 才能安全添加矿点和渔区。矿点、渔区的门/岸站位必须受同一个路径图约束，不允许「渔夫站河心、矿工穿山」等违和场景。

## 6. 推荐 v0.5 纵切片（先验证一个职业的真实价值）

**首选：河畔渔业 + 村心生活的一条完整链**，因为现有山谷最大的视觉识别是河流，能最快验证新生活方式是否会让世界更有生命力。

- 可发现但不固定解锁时间的渔点，实际安全钓鱼/捕鱼站位，季节性库存与少量可重复渔获。
- 一位乡邻真实转职；出门、下竿或下网、收鱼、搬鱼回村、晾鱼/做饭，居民需要才发展鱼棚。
- 鱼可补充真实的村庄粮食供给，能影响迁入上限，雨天/禁渔季改去其他工作。
- 有真实交易需求后，小鱼摊或邻里分享出现，而不是预制一个满座集市。
- 用户在 HUD/里程碑手账能查到本职业为什么出现、有谁参与、有多少鱼、村庄生活变化。
- 以 1× 演出和多季节/读档一致性作为验收，**通过后才复制到矿场与铁匠铺**。

### v0.5 完成标准草案

- **玩法**：无操作能形成一种专业生计，主动选择能影响另一种路线；节点状态不只更新文字。
- **资源**：产出/搬运/消耗守恒，食物分工可解决或解释长期饥荒；资源区域会被使用、开采和恢复。
- **社会**：至少一类新的职业迁入和临时旅客不混淆，总人口由工作、粮水、住屋与名望共同约束。
- **空间**：新增设施由真实节点合法选址，屋前可走，具有直观场景特色，不照抄前一栋建筑外观。
- **技术**：同 seed 多方针、不同 seed、流年/常速、旧 v4 存档、v3 旧谷全部回归；真实桌面/手机镜头人工审计与性能报告。
- **非目标**：完整商业模拟器、复杂战斗、实时 AI 对话、无边界地图和多人物精细骨骼一次到位均不属于首个 v0.5 切片。

---

**最终产品准则：** 生活方式成长树不应该被玩家看作「建造菜单」。应该让玩家在山谷里先看到某个真实问题和人的努力，再自然发现，下一种生活已成为可能。
