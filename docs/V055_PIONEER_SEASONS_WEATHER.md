## 技术与美术边界

- 天气绘制只保留一份实现：`src/graphics/weatherArt.ts`，新增可选的地形位置参数，不填写时保留 v0.3 的固定点位、6 处积水、22 条檐滴与原 `streakCount`。经典版也获得小幅三叉触地水花，其余模式不动。
- 开荒位置计算单独放 `src/graphics/pioneerAtmospherePlacement.ts`。真实保护树来自 `VALLEY_PINES` 的原有受保护位，不新增阻挡扩张的树木；水花点沿营地与树位产生，并以河流线段距离 / 岛屿椭圆裁剪，避免在河面、岛外随意溅水。所有位置同种子可重现。
- `src/graphics/pioneerSeasonalVfx.ts` 用经典同源的薄片 geometry、金/铜/粉调色板、InstancedMesh 批绘与周期落叶动画。秋叶只在秋天动，春瓣只在春天动；停顿/降动效时保留地面痕迹，停止大批动态叶子；没有模拟事件、真实伐木库存、人物增减或玩家选择副作用。
- 特效全部关闭 Raycaster，不能吞掉建筑/人物检视。降雨和落叶最多分别更新一个雨线 BufferAttribute、两个叶片实例矩阵；雨滴水花用额外一条动态线段 draw，无逐滴 Mesh。
- 冬雪仍跟原经典弧瓦面屋顶几何，保留 v0.5.4 建模、茶棚/渔棚劳动力与 v0.5.3 运鱼闭环。所有新居必须真建造。
- 这些是空气与地表 VFX，不等于加入真实降雨积水的生产惩罚、道路泥泞碰撞、水文模拟、存档中的落叶密度历史。**低端 Android 真机帧率和四季近景人工审美仍是未关闭的验收债**。

## 回归路径

1. `npm run test:sim`：原 115 项 + 新地面落点 22 处落在岛内且远离河道、经典天气默认积水/屋檐点数兼容、雨线尾低于头、雨水环可动态播放、未建房时无檐滴、真实长期建房后檐滴按建筑数出现、春秋冬实例显隐、降动效/手机上限、叶片时序位置变化。
2. `npm run check && npm run build:pages`，再跑双模式 Chrome 桌面与 390px 手机浏览器：旧 v0.3 不回退，开荒 0 房保留，五年真实房屋/人物/渔业/访客通过原回归。
3. `tests/pioneer-browser-smoke.mjs` 按真实世界日历走至春、秋、冬，并找到实际雨日；春≥70 花瓣、秋≥100 落叶/≥16 浮叶、冬≥12 地面雪块、雨天≥700 雨线、≥20 溅落点、≥3 积水以及真实屋檐滴水≥5。截图应分别显示花落/叶落/地雪/水花，不接受强行改画面特效开关冒充日期。
