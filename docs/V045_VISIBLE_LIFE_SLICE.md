# 守望谷 v0.4.5 · 看得见的村庄生活（可玩纵切片）

> 发布核对：v0.4.5-alpha.1 在 PR #17 通过 [94/94 模拟与桌面/手机浏览器 CI](https://github.com/mastercook777/Little-Haven/actions/runs/41781441954)，代码已合入 main（commit `41e52bae`）；尚需人工美术与真机性能审计。
>
> 2026-11-04 玩家反馈：「目前我还没有体验到太多的变化」。当前里程碑 v0.4.4-A/B/C 的系统是有效的，但大部分命运先决条件晚、成果隐藏在人物详情和抽象数值。**本轮先证明玩家看见改变，而不是新增无反馈的复杂系统。**

## 体验契约（开荒原模式）

**玩家承诺：** 同一座荒谷，从初夜到第一间棚屋、菜圃、火塘、迁入和田间传承，左侧文字、人物劳动、山谷模型以及可选择的实体都指向**同一份真实世界状态**；随时间发展，画面不能一直宣称「三人一火」。

- **开局 30–90 秒：** 非强制观察焦点说明谁为哪件事忙碌；可点「看这里」定位真实工地/森林/营火。不能冒出预建村庄。
- **第一间住屋：** 从「筹木」到「地基/梁架」到「有人住」，观察焦点跟随真实工地的状态。木料堆按实际库存起伏，建棚时木料已被扣库。
- **第一块菜圃：** 田里苗床根据同一菜圃 `field.stock / field.capacity`、季节真实变化；农忙/歉收可见。绝不因为改变 3D 绿叶就偷偷加粮。
- **生活里程碑：** 火塘、村心、迁入、试种成功等已发生的 journal / world 事实优先进入「此刻谷中」观察焦点；点它能检查真的人物/建筑/林地，不能打开不存在的实体。
- **手机：** 不增常驻大窗口。复用现有左上导语作为动态叙事，单个「看这里」轻按钮；移动端 390px 能点且不遮挡工具栏，屏幕阅读器可识别。
- **无人操作：** 所有生产/人口/事件流程继续自治；观察只是相机与真实实体详情，不修改时间、存粮、人物或存档。

## 架构

1. `src/ui/pioneerSpotlight.ts`：纯函数读取 `PioneerWorld` 并返回 `chapter,headline,detail,selection,kind`。优先级以最近的真实重大 journal 事件和实际设施状态为依据，旧档完全可用，无第二份故事时钟。
2. `pioneerMain.ts` 与 `pioneer.html`：用一张动态生活舞台替换永远静止的介绍词，页面按钮直接向现有 `chooseInspection` 传递可靠 ID，并平移已存在的 `OrbitControls` 镜头。关闭面板、重新开档、换槽后状态重算。
3. `pioneerVillage.ts`：存量可视物为园圃青苗、营地木料堆。田苗覆盖度来自现有字段；低库存确实裸露，回补后长起；冬季生长形态不同；木堆增减对应存粮木料，未盖成新结构前营地**仍无永久建筑**。视觉不产生资源或新碰撞实体。
4. `tests/pioneer-spotlight.test.mts` 与原有浏览器 smoke：初始、筹备工地、建成房屋、菜田、人口/命运记录、老档导入与新存档、桌面与手机点击后确实可检查，场景库存可视密度随实值改变。

## 非目标与守恒

- 本轮不修改 `PioneerWorld.schemaVersion=4`、旧 v4/v3 的任何存档 key，不修改 seed/迁居人口，不凭空追加江湖高手或世界战乱。
- 不是「村庄高级艺术风格完成」；仍需建筑质量审计、真实跨小时运输、人物专业绑定动作、美术实机评测。
- 用现有 `threejs-game-director` 统筹，`threejs-gameplay-systems` 保证事实触发，`threejs-game-ui-designer` + `references/ui-patterns.md` 约束轻界面，`threejs-qa-release` 和 browser smoke 做完整验收。不靠实时 LLM、API 或新美术素材工具。
- **验收重点：** 新开档、流年、重新进入都能感觉左侧章节和 3D 世界实际不同；如果在粮仓扣掉木料或收掉青菜，画面应正确变少；如果没有实体或真实历史，按钮绝不宣称「点击查看」。
