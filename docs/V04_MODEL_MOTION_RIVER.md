## 0. 目标与质量底线

**玩家承诺：** 守谷人一眼能看见一条穿过山谷并连到石桥的水脉；雨点从天而降；观察放置时能辨认屋舍用途、村民职业、自然的动作和生活节奏。
本轮继承清新手作低多边形微缩武侠风格，不改游戏剧情/世界时钟/存档格式，不将材质做成写实古建筑贴图。
工程顺序严格为：诊断 → 修方向与河 → 代表性建筑与人物动作改造 → 对照截图与自动化 → 合并上线。

## 1. Hotfix H1｜雨水倒流

### 复现及原因

- 截图显示雨纹仿佛向上升。`weatherArt.ts` 的 `animate()` 里为每个雨条计算 `baseY + t*speed`，这会让雨线**整体向 +Y 上升**，与起点低端 y-0.58 的形状无关。
- 静态截图只有雨线倾斜，无法证明动态方向；最终要用连续模拟时间中的世界 Y 位置比较而非截图猜测。

### 实施

- 拆出可测试的、无渲染副作用的 `fallingRainY(seed,time,speed,span)`：随时间严格向 **-Y** 运动，仅触底回卷到顶部；`LineSegments` 的头尾保持 y_head > y_tail。
- 雨帘不遮住主酒肆主体；檐滴、地面涟漪/积水保留。移动与减少动态效果模式仍受支持。

### 验收

- 同一雨粒子在无回卷区间，t 增加时 Y 明确变小；跨过底部时从顶部重生。
- 雨纹的两个端点上下顺序不颠倒；浏览器雨天至少三帧/视频验证真实向下运动。

## 2. Hotfix H2｜河流不可见

### 复现及风险判断

- `village.ts` 已有 x≈8.4、南北走向的河线和 x≈8.35 的横桥，但使用的 `ribbon()` 只是平面带，水面仅 1.81 宽，且为半透明，与周边地面和小径的色值接近。
- `ribbon()` 的水/岸与道路仅相差数厘米，岸带没有实在的河床/侧壁，不具备默认正交视角的清晰高差；河存在于代码不代表看得见。
- 确认河的位置是否与建筑、树丛和桥面重叠。新水系必须在自由旋转镜头下仍然连续；不可用前景一块孤立蓝贴片蒙混。

### 实施

- 将旧水面和假岸 ribbon 替换为 `riverArt.ts`：同一条中心曲线驱动的**实体水面、两侧斜坡/断面、河床深色衬底、浅滩、岸石与水纹**。
- 水体沿南北延伸到岛屿边界，桥在河面上方穿过且不再直接压在地上；与东西向道路的连接不被水覆盖。
- 对应季节色调改变水色；流纹由世界时间渲染，轻量、不会出现波纹向上飘的假象。

### 验收

- 默认 1440×900 与 390×844 截图中，河流在桥两侧都可辨认，且是**同一条连续水道**。
- 实际测试在默认镜头 + 旋转 45° 后不露缝，不透出河面下的主路/草地；波纹相对河岸移动。
- 建筑/河岸/桥栏杆无明显交叉，河上方的行人能从桥通过。

## 3. 建筑 Kit｜从盒子到有层次的山居

- **酒馆主楼**：双层独立剪影，屋脊脊兽简化、瓦当与屋檐收边、廊柱与横梁、格窗、木门分扇、窗台、招牌挂架、石基与台阶；优先默认相机看得见的正面和屋顶。
- **民居**：同一套兼容的基础部件按功能生成 3 组身份化变体（茶农晒架院、织娘窗格/檐棚、普通住家木门），有不同屋脊和窗的分配；不再全村统一的“盒子+灰屋顶”。
- **升级不破坏老化系统**：现有 `BuildingRenderer` 的脚手架、补瓦、新旧痕迹仍有效；`buildingId` 点击目标沿用现有顶层 Group。
- 模型局部重复件用共享 BufferGeometry / InstancedMesh；动态部件（酒旗、灯笼）保持独立 pivot。

## 4. 人物 Kit｜职业和体态要靠形状辨认

- 维持既有约 1.6–1.9 世界单位的角色尺寸、存档/职业映射，提升上半身/头部/肩背/腰带/袖摆、下摆与发饰的层次。
- 至少对掌柜、樵夫、织娘、渔夫、阿青做**形体差异**：围裙与托盘 / 肩背木具 / 头巾与腰带 / 斗笠鱼篓 / 剑鞘短披肩。
- 保留腿、双臂关节的命名 pivot，并增加肘部/上身/下摆/头部次级可控节点，避免纯色换装。
- 在默认缩放和 390px 手机视口检查剪影，不能只在近景漂亮。

## 5. 动作 Kit｜停走、接物、劳作、练剑

- 动作由模拟层 `activityId` 决定；渲染层只负责播放和插值。改进走路步态频率、膝/脚接地、转弯时上身跟随、停走缓动。
- 掌柜**扫地**含双臂带扫帚，**端茶**能保持盘面水平；樵夫**负重/劈柴**有躯干俯仰；茶农**采茶**有下蹲起身；织娘双臂交错；渔夫的鱼竿有抛竿/等待/收竿周期；阿青木剑至少起手/挥击/收势三相。
- 从移动转为动作须有 0.2–0.5 秒过渡；禁止腿部在原地持续跑步或突然反向 180°。
- `t` 是渲染模拟秒，不按画面帧数改变相位；暂停时 pose 和雨滴保持稳定。
