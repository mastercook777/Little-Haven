# v0.6.4 · 家家有自己的日子

在同一个村子里观察一天，应该看得到有人早出门，有人还在吃早饭。几个人在同一处做事，各自有地方站。年岁过去，已经住满的村子仍然会因为人的需求和付出的劳动而改变屋舍。

## 日常

- 同一处工作的村民分用可走的站位。先保留上一班仍合适的位置，换地方才走动。饭点轮换，日常歇脚尽量延续上一处位置。
- 清晨、傍晚按住户和日期错开。同一扇门允许连续通过，屋里没人时窗灯不亮。
- 闲下来的村民轮流使用自家院落。延用地块、路径、地形和室内出入口的通行规则。动作位置和行走时刻参与存档，逐段推进和流年使用同一套安排。

## 成熟住户的扩建

- 公共生活设施和居住需求达到一定规模后，住了至少 112 天、通路和屋况良好的住户可以排入改造。村中先满足优先工程和存量所需，再做住户扩建。两次这类工程完工至少相隔 34 天。
- 优先使用既有的付费木阁施工（4 木料、8 工时）。屋舍已有相应空间且资源足够时，再加有顶工作雨廊（6 木料、12 工时）。雨廊接入实际使用的院落，降低天气造成的额外磨损。已居住的地块和道路沿用原登记。
- 当前扩建范围是已入住住宅。新地块仍按实际住房和生产需求生长。

## 验证

以第 108 天作对照，每隔五分钟测量白天户外静止村民间的距离。种子 42 的近距离人对次数从 336 降至 4，默认种子从 152 降至 1。这里的距离阈值是 0.60 个场景单位。同一天两组清晨离屋从原先的 08:05–08:15 分布到 07:35–08:35。夜间进屋路径和存档恢复由模拟回归覆盖，多年推进验证木阁和雨廊出现在成熟住户的真实施工之后。
