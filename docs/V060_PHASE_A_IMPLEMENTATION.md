- `src/simulation/pioneerGrowth.ts`：真实户屋与木坊分别申请不同宽深的地块与木材/工时；住宅第二户面积较小，避免把所有家庭硬塞入大院；旧圈无地时允许**先真实清障**，清障没有完成不产生房屋。
- `src/graphics/homesteadScene.ts`：`foundation → frame → complete` 和原来的材料/时钟推进同步，院墙门洞、地坪、台阶、主屋和木作场同属一个落成的建筑实体。H3 侧翼必须在申请大地块时付足材料；已解锁木阁和锯台仍依据真实完成状态出现。
- `src/graphics/pioneerAtmospherePlacement.ts`：v06 雨檐使用同一屋顶规格及当地房屋坐标。季节雪沿已有更新循环开关。

- `tests/pioneer-v06-homestead.test.mts`：空白开局、户型与施工阶段、地块合法性、五年资源/工时、存档隔离的自动检验。

## 已知未完成、不能宣称已完成

1. **Phase 0 对照素材**：尚无按同 seed / 同相机 / 同季节 / 同像素规格建立并人工审看的 v0.5.6 与 v0.6 基线图库。测试通过不能代替画面盲审。
2. **更全面的聚落结构**：已有第一个庭院+作业场，但 `SettlementCluster`、邻里共享院落、多级地势可行走台地、真正 2.5D 人物足底位置与全村全建筑族尚未落地。
3. **建筑接地与雨雪**：主体台基与实际雨檐已接上；通用地表的五层 land-use、道路踩踏深浅、冬季非均匀薄雪尚未全村重绘。
4. **性能**：没有以全新五年成熟村量到经审核的 draw calls / triangle / GPU / 移动端帧率；700 calls 只是规划目标。
5. **人工美术闸门**：必须由未参与模型实现的观察者查看实机截图、无色剪影、四方向、手机视口，确认形体和生活关系显著区别于旧版，否则此 PR 不合入主分支。

## 建议的真实验收（在构建通过之后执行）

1. 基线 main：seed=42，开始、第一年、第三年、第五年，同默认相机，1440×900；另取盛夏/深秋/隆冬和雨景，记录真实建筑与 renderer.info。不能拿用户上传截图当作工具新生成的证据。
2. 当前分支：使用完全相同的时间与天气、`seed=42`；此外 `seed=20261103` 跑三/五年，确认不是手摆的 sample village。另拍 390×844 手机和灰度版。
3. 用户肉眼检查：至少三种有独立整体轮廓的功能屋、两处能讲清生计/通路关联的场所、从第一年到第五年的真实**主建筑**形变；禁止拿堆木桶、挂旗、季节换色替代。
4. 工程命令：`npm run test:sim && npm run check && npm run build:pages && npm run test:browser`。验证新存档往返、离线、资源守恒、可行走院门及未触碰经典模式。
5. 测性能：相机、DPR、canvas、draw calls、triangles、textures/geometries，同场景设置对齐；未有真实数据前不承诺 700/500 calls。

**当前发布决策**：这是开发预览分支，不是新主站的正式 v0.6.0。主站维持旧版本直至 CI、实图审美和用户审查合格。
