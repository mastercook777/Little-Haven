# 守望谷 v0.2 — 江湖初现 | Game design brief

**定位**：微缩武侠世界观察型放置游戏。玩家是无形的“守谷人”，不是村长、掌门，也不能操控居民。远方江湖主要发生在模拟层，村庄是可观察、可放大的唯一舞台。

## 玩家承诺

在一处与世隔绝的山谷中，观察酒肆、村民与过路旅人日常生活；一次不经意的善意可能改变一个少年此后数年的归宿，而没有玩家干预时，人物也继续活出自己的选择。

- **主要动词**：观察、放大、聆听传闻。
- **次要动词**：选择一次“机缘”，调节时间，查看人物近况与编年史。
- **奖励**：可见的人物成长、迁徙、建筑变化与带有因果的故事，而非资源弹窗。
- **压力**：旅人终会启程；错过选择不会游戏失败，而会自动发展为另一条故事。
- **留存钩子**：若干天后收到关于少年游历的消息，并亲眼看到其归乡。

## 本轮故事：少年阿青与江湖客沈问舟

1. 开局：山村日常，阿青在村口练木剑；酒肆备茶待客。
2. 当日稍晚：沈问舟由山道入谷，在酒肆停步。事件由**时间条件**触发。
3. 玩家可“留客一宿”或“顺其自然”。若始终不回应，次日默认顺其自然。
4. **留客**：师徒相识、练剑；阿青外出历练；书信传来；归乡后开设「竹隐剑庐」。
5. **顺其自然**：阿青自行寻得武学启发，随商队游历；江湖传闻传回；归乡后修建「行脚茶亭」，接待来往行人。
6. 两个分支都必须改变人物路线、地图建筑和编年史。两条路径没有明显的“好/坏”之分。

## 最小闭环与验收

**观察 → 山道来客 → 留客/不扰 → 相遇或自学 → 游历 → 风闻 → 归乡 → 地景改变。**

- 进入游戏即可看见中式瓦屋、竹林、木质酒幌、练武坪与沿山道延伸的石桥。
- 旅人从山外来到酒肆，阿青有独立的练武动作；游历时人物离开场景，归乡后重新出现。
- 重要场景变更与模拟状态严格对应，不依赖弹窗模拟“完成”。
- 通过 12× 流年快进可以观察完整故事；正常速度适合闲看。
- 不采用大模型实时写剧情；事件基于可测试、确定性的规则。
- 旧版本数据使用不同 localStorage key 保留，不覆盖 v0.1 记忆；新江湖篇章从第一天开始。

## 非目标

不做武功技能树、即时战斗、复杂门派关系、官府征税、盗匪袭村、真实开放世界或 AI 文字生成。本版只验证**一条有两种结局的角色人生故事链**，为以后可组合人物/世界系统打基础。

## 三层游戏时间

- **场景短时**：人物行走、开店、练习、昼夜灯光。
- **一日事件**：旅人来访、守谷人选择、训练阶段。
- **多年故事**：游历、传闻、归乡由压缩的“故事流年”实现，避免玩家真实等待数年。

## 风险与对应

- 武侠化只剩换皮 → 验收必须看得到阿青阶段变化与两条不同结局。
- 过多文字覆盖画面 → 风闻只占原右上小面板，故事承载以人物行动和村景为主。
- 离线期间自动错过选择 → 没有失败和永久惩罚，默认分支也能构成完整故事。
- 旧存档不兼容 → 使用 v0.2 专用存档键，保留原键，明确记录。
