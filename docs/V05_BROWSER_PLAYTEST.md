## 5 分钟内观察一座真正发生变化的村庄
1. 打开在线游戏，先看一眼河道：它现在应贯穿村庄东部、穿过桥下，且河槽比两岸低。
2. 若你已有旧进度，可以打开 **守望录 → 存档**，切换到另一个槽位；需要对比时可以**仅重开当前槽位**。注意提前导出希望保留的记录。
3. 在全新存档里连续点击 **「流年」两次**，来到第 1 年秋季；右侧出现「水脉与村路」机缘时，选择**山桥商路、河畔渡口或田园共居**中的一个。放着不理，乡邻一个季节后会自行选择田园。
4. 继续点击 **「流年」四次左右**，建筑会经历地基、施工、主设施落成；再推进约三季，可看到产业区进一步发展。不需要逐项收集物资，乡邻自动备料和工作。
5. 观察新区域是否改变了轮廓、占地和居民行动。切换到另一个存档槽位重新尝试不同路线，用同一默认相机和季节比较。

## 这次重点请反馈
- **河流：** 一眼能否看出穿过山谷的连续溪流？桥/地形是否有遮挡、穿模、悬空？
- **村庄：** 三条不同路线推进两年后，能否不看 UI 认出来？新增设施是否挡住主路、树木、旧建筑？
- **生活：** 商路的货郎、渡口的渔夫、果园的茶农是否在新场所做事？
- **动作：** 阿青白天练剑时是否像一个有腰胯、步法和剑的剑客？有没有卡顿、挥剑像耕地、站姿穿模？
- **性能：** 设备、浏览器、大概的流畅程度、出现问题的年份/季节/天气。

## 已知边界（本轮不冒称完成）
- 阿青已经采用正式 `AnimationClip`、`AnimationMixer` 与渐变切换，但仍使用现有分件模型，并非美术师重做的高质量 skinned GLB。
- 其他村民的行动路径仍是确定性的职业时段路线，没有精细的对向碰撞和完整 A*。
- 三条路线的初版模型主要用于验证可见的村庄成长，而非正式的 AAA 品质建筑资产。
- 浏览器自动化覆盖桌面 Chromium 和 390px 移动视口，但低端安卓真机 FPS 仍需设备实测。

**反馈时直接发一张页面截图，或说明年份、季节、天气和选择路线即可。**
