# v0.6.2 西麓开拓

开荒者在溪边点火。前两座山居仍在原有生活圈内选址。第三户提出建屋需求后，村民会先勘察西麓，为带偏屋的山居找足完整宅地。后续住宅优先沿西麓已走出的路和既有住家布置，逐步形成邻里。

- 将开荒地图的西端向外扩展，新增地面从开局就以荒地呈现。东岸、溪流和原来的营地坐标沿用现有地图。
- 西麓完整宅地必须有一条可步行的进场路线。居民须投入八工时清灌移石，之后住宅沿用备料、施工、落成和实际迁居流程。
- 已住进新宅的居民走到真实院门，回家时继续走入可站立的前院。已有道路、资源点和保护树仍参与碰撞与寻路。
- 以同一镜头查看新营地和第五年村庄。验证默认种子和种子 42 是否能通过自治流程建成带偏屋的山居，以及旧档续玩是否保留原有房屋和道路。

本轮聚焦扩地与住宅。高低台地、私人院内更细的生活路线、产业分区和长期人口规则是后续迭代。

### 实测

以 PR #31 合并提交为基线，西侧名义半径从 18.5 加到 27.5，西麓中段另加纵深供相邻宅地使用。模拟到第 108 天，种子 42 西麓有两户，网页默认存档种子 20261296 有三户。两者都自然建成并入住带偏屋的 H3，材料为 14 份木料，施工需要 23 工时。回归测试覆盖清障中途导出后续玩、沿实际道路可达，以及同户居民走过院门并使用不同的前院位置。

本轮沿用 12 人的需求上限。已住满且无新住房需求的旧存档可以继续玩，观察这条成长线可以从新档开始。
