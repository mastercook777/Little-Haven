# v0.2 第一条江湖故事链 — 事件/状态规格

## 状态

`peace → stranger → training → departed → rumor → returned → legacy`

`choice = null | host | observe`，`storyStarted` 为首次选择或自动选择的模拟分钟数。故事独立于 Three.js，推进函数支持跨越多个阈值的大步长和离线结算。

| 阶段 | 触发 | 外观反馈 | 持久影响 |
| --- | --- | --- | --- |
| stranger | 第一天 09:40 | 沈问舟进入山道，酒肆等待来客 | 守谷机缘出现 |
| training | 选择后 +120 分钟 | 阿青练剑；若留客则侠客旁观指导 | 日记留痕 |
| departed | +1500 分钟 | 阿青离开本地渲染 | 出游纪事 |
| rumor | +3000 分钟 | 面板呈现远方江湖来信 | 江湖声望增长 |
| returned | +4500 分钟 | 阿青归乡、服饰变化 | 人物归来 |
| legacy | +5600 分钟 | 剑庐/茶亭出现；额外旅人加入 | 地图与人口/屋舍变化 |

如果到第二天上午 10:00 仍未选择，则自动使用 `observe`，保证村庄无人干预时也会继续发展。玩家的选择不是胜负：两条路线可以形成不同的生活中心。日记只记录一次，时间跨度大时通过顺序遍历阶段写全事件，避免漏故事。

## 测试合同

- 初始化静态一致且无依赖浏览器 API。
- 同步/大步长推进具有相同最终事件阶段与顺序。
- `host` / `observe` 的终局建筑和叙事各不相同。
- 无玩家选择仍能自动发展。
- 页面存档与离线读取不重复事件、不覆盖旧键。
- 游历时阿青不可见，归乡时恢复；江湖客在逗留阶段可见。
